# 传讯 - 聊天应用

一个现代化的网页聊天应用，具有美观的界面和丰富的功能。

## 功能特点

- 🎨 多种主题颜色（金色、蓝色、紫色、绿色等）
- 🌙 深色/浅色主题切换
- 💬 多对话管理
- 😊 表情符号支持
- 📱 响应式设计，支持移动设备
- 💾 本地存储聊天记录
- ⚡ 流畅的动画效果

## 技术栈

- HTML5
- CSS3 (自定义CSS变量)
- 原生JavaScript (ES6+)
- Font Awesome 图标
- Google Fonts

## 部署说明

本项目已部署在GitHub Pages，可以通过以下步骤部署到您自己的GitHub账户：

1. Fork 本仓库
2. 在Settings > Pages中启用GitHub Pages
3. 选择main分支作为源
4. 访问您的个人GitHub Pages地址

## 使用方法

1. 从左侧列表选择或创建新对话
2. 在输入框中输入消息
3. 按Enter发送消息，Shift+Enter换行
4. 点击表情符号图标添加表情
5. 点击顶部切换主题和颜色

## 浏览器支持

- Chrome 60+
- Firefox 55+
- Safari 12+
- Edge 79+
